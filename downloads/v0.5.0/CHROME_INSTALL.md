# NERO Swipe Reader：Chrome版の導入手順（v0.5.0）

PCのChromeへ、デベロッパーモードで無料導入する手順です。Chrome Web Storeへの登録や支払いは不要です。Google・Mozillaのストア審査を経由しない配布方法です。

対象はWindows・Mac・LinuxのChrome 120以上です。最新版をおすすめします。**iPhone・iPad・AndroidのChromeには導入できません。** Firefox用のXPIとは別のファイルを使います。

## 1．ZIPをダウンロードして解凍する

1. PCで[Chrome版ZIPをダウンロード](https://raw.githubusercontent.com/neronote100/nero-swipe-reader/main/downloads/v0.5.0/nero-swipe-reader-0.5.0-chrome.zip)します。ファイル名は `nero-swipe-reader-0.5.0-chrome.zip` です。
2. ZIPを解凍します。Windowsは右クリック→「すべて展開」、MacはZIPをダブルクリックします。
3. 解凍した中身を、書類／ドキュメント内の `NERO Swipe Reader` など、今後も保管するフォルダーへ置きます。
4. そのフォルダーを開き、直下に `manifest.json` があることを確認します。

**導入後も、このフォルダーは削除・移動せずに保管してください。** Chromeはここにあるファイルを読み込んで動きます。会員向けウォッチリストのJSONは、拡張機能のファイルとは別に保管します。

## 2．Chromeへ追加する

1. Chromeのアドレス欄へ `chrome://extensions` と入力して開きます。
2. 右上の「デベロッパーモード」をONにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. 手順1で用意した、**`manifest.json` が入っているフォルダー**を選択します。ZIP自体や、その一つ上のフォルダーは選びません。
5. 一覧へ「NERO Swipe Reader」が追加されたら、アドレス欄横の拡張機能アイコン（パズル形）を押し、ピン留めします。

Macでは「選択」、Windowsでは「フォルダーの選択」など、確定ボタンの名前が異なる場合があります。選ぶ対象は同じです。この読み込み方法は[Chrome公式の導入手順](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)でも案内されています。

## 3．noteへログインして接続する

1. **同じChrome・同じプロフィール**で [note](https://note.com/) へログインします。Firefoxでのログインは引き継がれません。
2. ピン留めしたNEROのアイコンを押します。リーダーが新しいタブで開きます。
3. 「再確認」を押し、「接続中 @自分のユーザーID」と表示されることを確認します。

ツールや設定ファイルへ、noteのパスワードを入力する必要はありません。投稿前には表示されているアカウントを確認してください。

## 4．ウォッチリストを入れる

1. 会員向けに別途配布されたJSONファイルをダウンロードします。拡張ZIPには会員名簿を入れていません。
2. リーダーのウォッチリスト欄で「読み込み」を押し、JSONを選択します。
3. 登録人数と選択中のリストを確認し、「新着記事を取得」を押します。

城下町メンバーと追加10個の合計11リストを切り替えられます。各リストは最大200人までです。手動追加もできます。

Firefox版から移す場合は、Firefox版で各リストの「保存」からJSONを書き出し、Chrome版で読み込みます。**リスト以外の下書き・送信履歴・ログイン状態は移行されません。** JSONにアカウント指定がある場合は、指定されたnoteアカウントで読み込んでください。

## 読む・スキする・返信する

- 通常取得：スキ済みを飛ばして、1人につき未スキ記事を最大3本集め、全体をランダム表示します。「スキ済みの記事も含める」をONにすると最新3本ずつが対象です。
- 深掘り：ユーザーIDかプロフィールURLを1人分入力し、最大50本を取得します。こちらもチェックでスキ済みを含めるか選べます。記事不足などで本数が少なくなる場合があります。
- 記事内リンク：note記事はリーダー内で開き、「リンク元へ戻る」で読んでいた位置へ戻れます。外部サイトは別タブで開きます。
- スキ・コメント：表示中の記事が送信先です。返信待ちの「一括取得」で、自分の記事の未返信コメントを確認できます。本人がスキ済みのコメントは対象外です。
- コメントへのスキ：「コメントにスキ」から送れます。返信時は「返信先のコメントにもスキを送る」が初期ONです。OFFなら返信だけを送ります。

取得中は**リーダーのタブを開いたまま**にしてください。別のタブで作業しても構いません。長い取得はリーダーのタブで動くため、Chromeのバックグラウンド処理の停止に影響されにくい構成です。

リーダーの再読み込み・タブを閉じる操作・Chrome終了で、進行中の取得は停止します。記事取得は再実行してください。未返信の確認済みキャッシュは保存され、次回の「一括取得」で差分を確認できます。処理全体が自動再開するわけではありません。

送信結果が不明になった場合は、**再送する前にnote側で結果を確認**してください。コメントを自動再送する機能はありません。返信済み・スキ未完了の場合は「スキのみ再試行」で、返信を増やさずにスキだけ送れます。

## 新しいバージョンへ更新する

1. 各ウォッチリストを「保存」からJSONでバックアップします。
2. リーダーのタブを閉じ、新版のChrome用ZIPを解凍します。
3. 初回に用意した**同じ保管フォルダー**へ、新版の拡張ファイルを上書きします。会員JSONやバックアップファイルは上書きしません。
4. `chrome://extensions` を開き、NERO Swipe Readerの再読み込みボタン（丸い矢印）を押します。
5. アイコンからリーダーを開き、接続アカウントとリストを確認します。

設定を残すため、更新時に拡張機能を削除して入れ直す必要はありません。配布版は同じ拡張IDを使います。ストア経由の自動更新はないため、新版が案内されたらこの手順で更新してください。

## うまくいかないとき

| 状況 | 確認すること |
| --- | --- |
| 「マニフェストを読み込めません」と出る | ZIPを解凍し、`manifest.json` が直下にあるフォルダーを選びます。 |
| 導入後に動かなくなった | 保管フォルダーを削除・移動していないか確認し、拡張の再読み込みを試します。 |
| noteへ接続できない | 同じChromeのプロフィールでnoteへログインし、「再確認」を押します。noteへのサイトアクセスが許可されているかも確認します。 |
| 別のタブで開いていると表示される | 開いているリーダーへ戻ってください。重複送信を防ぐため、同じChromeプロフィールでは1つのリーダーを使います。 |
| 取得が止まった・本文が表示されない | 回線とnoteの表示を確認し、取得をやり直します。スキ・コメントはnoteで結果を確認してから操作します。 |

## 通信と保存について

記事やコメントの取得、スキ・コメントの送信ではnoteと通信します。ログインには、Chromeがnoteへの通信へ自動添付する既存のログイン用Cookieを使います。画像表示では画像配信元へ接続し、外部リンクを選ぶとそのサイトを開きます。

ウォッチリスト・下書き・未返信キャッシュなどは、利用中のChromeプロフィール内へ保存します。開発者サーバーへのデータ収集、アクセス解析、外部AIへの送信はありません。[プライバシー方針](https://github.com/neronote100/nero-swipe-reader/blob/main/members/PRIVACY.md)と[公開ソース](https://github.com/neronote100/nero-swipe-reader)も確認できます。

このツールには会員資格の自動確認機能はありません。配布先の管理は、メンバー向けページ側で行います。

Mac・Windowsの実アカウントでの表示・投稿は、別途確認が必要です。導入できたことと、実際のnote上で全操作を確認したことは分けて案内しています。
