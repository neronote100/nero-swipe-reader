## 変更点

- 通常取得は、新しい記事からスキ済みを飛ばして1人最大3本の未スキ記事を集めます。必要に応じて古いページも探します。
- 通常の「スキ済みの記事も含める」をONにするとスキ済みを含む最新3本ずつを取得します。
- 深掘りモード：1人のユーザーIDかプロフィールURLを指定し、未スキ記事を最大50本取得します。深掘り側のチェックをONにするとスキ済みを含む最新50本が対象です。
- どちらも対象全体をランダム表示。チェック状態と深掘り対象をアカウント別に保存します。
- 記事不足・状態不明・通信失敗・探索上限・中断は途中結果として表示します。

拡張IDと権限を維持し、既存リスト・下書き・コメントへのスキと返信機能を引き継ぎます。会員名簿は含みません。
