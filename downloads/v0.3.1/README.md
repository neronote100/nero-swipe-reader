## 変更点

- 返信待ちコメントへのスキ送信。
- 返信に続いて同じ元コメントへのスキ送信（返信欄でON/OFF可能）。
- 返信だけ成功した場合は成功状態を保持し、スキだけを再試行。返信本文を再送しない。
- スキ未完了の情報を端末内に保存し、再読込後も再試行できる。

拡張ID・権限・通信先は維持しています。スキ送信の単体・統合・画面処理モック検査、形式検査に合格。web-ext lintはエラー・警告0件。ソースZIPからの再ビルド結果は本体の全ファイルと一致します。実際のnoteアカウントへの送信とv0.3.1のMozilla署名は未実施です。

ソースのルートでNode.js 22以降を使い `npm run build:members` を実行すると `dist/firefox-members/` が生成されます。詳細はソース内の `MOZILLA_BUILD.txt` を参照してください。
