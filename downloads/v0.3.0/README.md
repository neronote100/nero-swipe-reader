# Mozilla更新提出用 v0.3.0

- **拡張本体**：`nero-swipe-reader-0.3.0-unsigned.zip`（最初のアップロード欄へ）
- **ソースコード**：`nero-swipe-reader-0.3.0-source.zip`（ソース提出欄へ）

既存のNEROアドオンの管理画面から「新しいバージョン」を提出してください。拡張IDは維持しています。署名後のXPIがインストール・配布用です。ZIPをXPIに改名して配布しないでください。

## 変更点

- 城下町メンバー＋10個のウォッチリスト。切り替え、名前変更、JSON読み込み、保存。
- 旧登録を「旧ウォッチリスト」に移行し、下書きを保持。
- 各ユーザーの直近3記事から本人スキ済みを除外し、全体をランダム表示。
- スキ不明・取得失敗を未スキ扱いにせず、件数を表示。進捗・中断対応。
- 取得中のリスト切り替えでも古い記事が混入しない。

個別の名簿はこの公開ZIP・ソースに同梱していません。別途渡された設定ファイルを、拡張更新後に「読み込み」で一度取り込むと、端末内に保存されます。

## リリースノート（貼り付け用）

ウォッチリストを11個保存・切り替えできるようになりました。各ユーザーの直近3記事から本人がスキ済みの記事を除外し、全対象をランダムに表示します。旧ウォッチリストと下書きは引き継ぎます。

## 審査担当者へのメモ

拡張IDと必要な権限に変更はありません。通信先は従来と同じnote.comです。ウォッチリストのJSONは端末内で読み込み、開発者サーバーへ送信しません。名簿は本体に同梱していません。記事取得は利用者の操作時だけ行い、自動スキ・自動コメントは追加していません。

Node.js 22以降を使用し、提出したソースZIPのルートで `npm run build:members` を実行すると `dist/firefox-members/` に生成されます。ソースZIPからの再ビルド結果が本体の全ファイルと一致することを確認済みです。

既存回帰検査、新規モデル・フィード・キャッシュ迂回の検査に合格。モック接続の画面操作で52件読み込み・切替・再読み込み・遅延応答隔離・モバイル表示を確認。web-ext lintはエラー・警告0。実アカウントでの新機能確認とv0.3.0のMozilla署名は未実施です。
