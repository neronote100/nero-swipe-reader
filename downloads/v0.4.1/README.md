# Mozilla更新提出用 v0.4.1

- **拡張本体**：`nero-swipe-reader-0.4.1-unsigned.zip`（60,336バイト。最初のバージョンアップロード欄へ）
- **ソースコード**：`nero-swipe-reader-0.4.1-source.zip`（ソースコード提出欄へ）

ファイル自体をダウンロードし、解凍せずにそのまま提出します。保存した名前が`.zip`で終わることを確認してください。既存アドオンの「新しいバージョンを提出」から登録し、メンバー配布にはMozilla署名後のXPIを使います。

## 変更点

- 記事本文で消えていたリンクカードを表示します。noteカードは表示位置の近くからタイトル・画像・概要を補完します。
- noteの記事リンクはSwipe Reader内で開きます。「リンク元へ戻る」で元の記事と読んでいた位置へ戻れます。複数のリンクをたどる場合も対応します。
- リンク先の記事へスキ・コメントを送れます。記事IDだけの埋め込みリンクは正式URLを確認してから送信を有効にします。
- 外部サイトや記事以外のnoteページは別タブで開きます。本文内の見出しリンクはその位置へ移動します。
- 元のフィードの順序・位置と、既に開いた下書きの送信先を保持します。

拡張ID・権限を維持しています。v0.4.0の通常取得・深掘り・ウォッチリスト・コメント機能を引き継ぎ、会員名簿は同梱しません。
