# NERO Swipe Reader v0.6.0

投稿日時による並べ替えと、企画・イベント向けのハッシュタグ検索を追加しました。Chrome版・Firefox版に共通の更新です。

## ダウンロードするファイル

- **`nero-swipe-reader-0.6.0-chrome.zip`**：PC版Chrome用。解凍してフォルダーを読み込みます。[導入・更新手順](CHROME_INSTALL.md)
- **`nero-swipe-reader-0.6.0-unsigned.zip`**：Firefox用のMozilla提出本体。通常のメンバー配布には、Mozillaから取得した署名済みXPIを使ってください。
- `nero-swipe-reader-0.6.0-source.zip`：Mozillaのソース提出欄で使う再ビルド用ソース。本体のアップロード欄には選びません。
- `nero-swipe-reader-0.6.0-chrome-source.zip`：Chrome版の再ビルド用ソース。一般利用者の導入には不要です。

## 並べ替え

記事エリア上部の「並び順」から、ランダム・投稿日時の新しい順（降順）・古い順（昇順）を選べます。年月日・時・分・秒を含む日時で比較し、日時不明の記事は最後に置きます。

対象は**すでに取得した記事の範囲**です。たとえば新しい100本を取得して「古い順」にしても、その人・タグの最古の記事から全件を探し直す機能ではありません。読んでいる途中で変更した場合は現在の記事とスクロール位置を保ち、前後の移動順を変えます。最初から順に読む場合は、並び順を選んでから取得してください。

## ハッシュタグ検索

1. 「ハッシュタグで企画・イベント記事を探す」を開きます。
2. `#企画名`、`＃企画名`、タグ名、またはnoteのタグURLを1つ入力します。
3. 上限を50・100・200本から選びます。初期値は100本です。
4. 必要なら「スキ済みの記事も含める」をONにして、「このタグの記事を取得」を押します。

ウォッチリスト外も含め、そのタグが実際に付いたnoteの公開記事を新しいものから探します。キーワードや関連トピックでの検索へ置き換える処理はありません。スキ済みを含めない場合は、スキ済み・状態を確認できない記事を飛ばして次の候補を探します。通常取得・深掘りとはチェックを別々に保存します。

取得上限・探索上限・通信エラー等で全件を集められないことがあります。途中結果や未取得記事が残る可能性は画面に表示し、中断時は確定した記事を残します。

## Chrome版を更新する

リーダータブを閉じ、今の拡張フォルダーへ新版ZIPの中身を上書きし、`chrome://extensions`で拡張を再読み込みします。**拡張を削除する必要はありません。** 同じ拡張IDと保存データを引き継ぎます。

同じChromeプロフィールでログインしたnoteタブを開き、NEROで「再確認」を押してください。取得・送信中はnoteタブとリーダータブの両方を開いたままにします。v0.5.1のログイン確認・通信の修正も含まれています。

## 検証

共通機能とChrome向けの自動検査が通過しています。秒単位・タイムゾーンを含む日時比較、取得中の順序変更、リンク先からの戻り位置、タグの入力検証、上限・未スキの補充・中断・途中結果・アカウント切り替えを確認しました。Chrome生成物の通信検査では、noteタブの別コンテキストを再現し、実際の生成エンジンからタグ取得を行っています。Firefoxのweb-ext検証はエラー0・警告0です。

ソースZIPから再ビルドしたChrome・Firefox本体が配布ZIPとバイト単位で一致することを確認しています。実際のChrome・Firefoxとnoteのログイン状態での動作確認は、この実行環境では未実施です。

会員名簿・パスワード・Cookie・秘密鍵は含みません。通信先と保存内容は[プライバシー方針](https://github.com/neronote100/nero-swipe-reader/blob/main/members/PRIVACY.md)を参照してください。
