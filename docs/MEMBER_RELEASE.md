# メンバー版の配布と実機確認

## 現在の成果物

- ソース：`members/`、既存のnote API処理は`extension/`と整合性確認付き`packed/`からビルド時に取得。
- ビルド：`npm run package:members`
- 出力：`dist/firefox-members/`、`dist/nero-swipe-reader-0.2.0-unsigned.zip`
- 拡張ID：`swipe-reader@neronote100.github.io`。旧Bridgeとは別ID。
- Firefox 140以上、Android版142以上。

## 公開前に実アカウントで確認する項目

- [ ] PC版Firefox：一時読み込み後、ツールバーから画面が開く。
- [ ] Android版Firefox：Mozilla署名済みXPIでインストールと起動ができる。
- [ ] ログアウト時はログイン案内が出る。ログイン後に「再確認」で本人が表示される。
- [ ] ウォッチリストに2人以上追加し、最新記事・本文・画像・前後操作を確認。
- [ ] 長い本文はスクロールでき、末尾で上へスワイプした場合だけ次の記事へ進む。
- [ ] 自分のテスト用記事でスキ・コメント・返信がnote側に1回だけ反映される。
- [ ] 返信待ちの取得で、返信済み・スキだけ済み・返信後に再コメントの3種類を照合。
- [ ] 全件再確認・取得中断・通信エラー時の部分結果と失敗件数を確認。
- [ ] 別コメントの下書きを切り替え、再読み込みして復元を確認。
- [ ] noteのアカウントを切り替え、古い画面からの送信が拒否されることを確認。
- [ ] 送信中に回線を切る、タブを閉じる。再送が自動実行されず、noteで結果確認を案内する。
- [ ] 保存データ削除で、そのアカウントのウォッチリスト・下書き・キャッシュ・重複防止情報が消える。

noteの実アカウントに接続していない開発環境では、このチェックを完了扱いにしないでください。

## Mozilla署名

1. `npm run package:members` を実行。
2. Mozilla Add-on Developer Hubで新しいアドオンを登録し、配布方法「このサイト以外で配布」（unlisted）を選択。
3. ZIPをアップロード。説明・プライバシー方針・必要なソースを提出。
4. 審査・署名後のXPIをダウンロード。署名前のZIPを配布用XPIに単純に改名しない。
5. PCとAndroidの通常版で署名済みXPIを確認し、メンバー向けページに設置。

Mozillaの開発者アカウント・署名資格情報はリポジトリへ保存しません。将来の更新でも拡張IDを保持し、バージョンを上げて再署名してください。現状は手動更新です。

## 仕様と制限

- ウォッチリストは手動登録で、noteのフォロー一覧とは別。1人につき最新の1記事を取得。
- 返信待ちは自分の記事が対象。スレッド上の返信順で判定し、相手個別への意味的な返信関係までは推測しない。
- 記事一覧の列挙中は中断要求が即時反映されず、コメント走査に移った時点で停止する場合がある。
- 未返信キャッシュは差分更新。削除・編集等を直ちに照合したいときは「全記事を再確認」を使う。
- 結果が不明な同一本文・記事・返信先への投稿は24時間再送を防止。noteで未送信を確認してもこの保護は自動解除しない。
- コメントは500文字以内。通信不明時の下書きは保持する。
- note本文の埋め込み動画等は表示対象外。元記事リンクから確認。
- 公開リポジトリにメンバー認証機能はない。配布先の限定とアドオン利用者の資格認証は別の要件。
