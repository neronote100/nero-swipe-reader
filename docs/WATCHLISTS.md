# ウォッチリストの使い方（v0.3.0）

## リストを切り替える

「城下町メンバー」と「リスト1」〜「リスト10」の合計11枠を使えます。各リストは最大200人まで保存できます。選択欄で切り替え、「名前を変更」で分かりやすい名前を付けてください。

v0.2.1以前の登録は「旧ウォッチリスト」に自動移行します。既存の返信下書きも引き継ぎます。登録内容は、ログインしているnoteアカウントごとにこのFirefoxの端末内へ保存します。

## 用意済みの設定ファイルを登録する

1. 同じFirefoxでnoteへログインし、リーダーで「再確認」を押します。
2. 「読み込み」から、別途渡されたウォッチリストのJSONファイルを選択します。
3. ファイル内にリストIDがある場合はその枠へ、ない場合は現在の枠へ追加します。同じユーザーIDは重複登録しません。他のリストは変更しません。
4. 「未スキの新着記事を取得」を押します。

ファイルに`owner`がある場合、そのnoteアカウントでのみ読み込めます。会員名簿は公開ソースや配布ZIPに同梱していません。利用中のFirefoxの保存領域へ開発者が遠隔書き込みする機能もありません。設定ファイルを一度読み込むと、次回以降も登録内容が保持されます。

「保存」は選択中のリストをJSONで書き出します。返信下書き・コメントの送信履歴・認証情報は含みません。会員名簿を含む場合は、バックアップや共有の保管先を確認してください。

## 記事の取得ルール

- 選択したリストだけが対象です。
- 各ユーザーの公開記事一覧の先頭ページから、公開日時が新しい順に3記事を選びます。非公開記事は取得しません。
- この3記事のスキ状態を毎回確認し、ログイン中の本人がスキ済みの記事を除外します。対象が減っても4記事目以降から補充しません。
- スキ状態を確認できなかった記事は未スキ扱いにせず除外し、画面へ件数を表示します。取得失敗と記事なしも別々に表示します。
- 全員分の確認が終わってから、対象全体をランダムに並べます。登録順や通信完了順が表示順に使われません。ランダムなので、同じ著者が偶然続く場合はあります。
- 取得中の進捗を確認でき、中断時は確認できた分を表示します。取得中に別のリストへ切り替えた場合は、古い結果を表示しません。

## 手動で追加・修正する

ユーザー名またはnoteのプロフィールURLを入力して「追加」を押します。「×」は現在のリストからだけ削除します。ID未照合のメモがある場合は「IDを登録」から確定したユーザー名を入力できます。名簿はウォッチ対象であり、有効なメンバー資格を自動判定する仕組みではありません。

## 設定ファイルの例

```json
{
  "format": "nero-watchlist",
  "version": 1,
  "owner": "your_note_username",
  "list": {
    "id": "castle",
    "name": "城下町メンバー",
    "users": ["example_creator"],
    "pending": []
  }
}
```

`castle`が城下町枠、`list-1`〜`list-10`が追加枠です。これは形式説明用のダミーデータです。
