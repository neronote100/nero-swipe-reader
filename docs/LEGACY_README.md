# NERO Favorite Reader 🌙

`ネロのお気に入り🌙` 専用の独立Swipe Readerです。GitHub Pages + Firefox拡張で動作し、noteのログイン情報を外部サーバーへ保存しません。

## v0.1.44 — App Rebuild

v0.1.44では、機能追加で複雑になっていたReaderをアプリとして再整理しました。

### 通信基盤

- Readerページ側で実行するcontent scriptを **`app-bridge.js` 1本**へ統一
- 長いコメント確認は `NERO_APP_V2` の長寿命Portで実行
- 拡張を認識した状態と、noteアカウント確認成功を別々に判定
- note確認に失敗しているのに「接続正常」と表示しない
- 長い走査は進捗表示・中断・途中保存に対応
- Readerページ全体を監視する旧MutationObserverベースのBridgeはv0.1.44では読み込まない

### 5画面

- **ホーム** — 接続状態、返信待ち、コメント相手、スキ返し、自動運転の概要
- **コメント** — 返信待ち / コメントをくれた人・最新記事
- **読む** — 検索、Swipe Reader、記事本文・画像表示
- **お返し** — 指定記事へのスキ返し、対象記事一覧
- **管理** — 自動運転、過去スキ整理、再スキャン、診断、履歴

### 返信待ちコメント

- 本人の記事コメントを確認し、**本人が返信していないコメントだけ**を一覧化
- コメントへスキしていても、返信していなければ返信待ちに残す
- Readerから返信可能
- 通常更新はコメント数が変わった記事、返信待ちが残る記事、一定期間未確認の記事を中心に差分取得
- 全件再確認は管理画面から明示的に実行
- コメント取得の同時通信数を抑え、Firefox for Androidの負荷を軽減

### コメントをくれた人

- 直近30日のコメント相手を集計
- 1人1件の最新記事を取得
- コメント日時が新しい人を優先
- 通常は差分更新し、全件再確認は管理画面へ分離

## 記事本文表示

Readerでは概要だけでなく、note API v3から記事本文を読み込みます。

- 見出し、段落、改行、リスト、引用、リンク
- 本文画像・GIF・figure/figcaption
- コードブロック
- script/style/noscriptを破棄し、安全なURLだけでDOMを再構築

## 指定記事へのスキ返し

`https://note.com/nero_notelover/n/ne4843208abbe` にスキまたはコメントをくれた人を取得し、その人の最新記事へ1人1回だけスキを返します。

- コメントをくれた人を優先
- 新しいスキは **1分以上** あける
- すでにスキ済みの記事は待たずに次へ進む
- 返礼済みユーザーをFirefox端末内へ保存し、重複返礼しない
- 対象記事一覧を随時更新可能
- noteのスキ制限を検知したら既存クールダウンを優先

## 自動運転 / 過去スキ整理

既存機能はv0.1.44でも維持しています。

- 自動運転は5分おきに候補を処理
- `ネロのお気に入り🌙` への通常自動追加は直近60分で最大10件
- スキ制限中もマガジン追加は継続
- 過去スキ整理は12秒以上あけて順番に処理
- 進捗・結果・返礼済み履歴はFirefox `browser.storage.local` に保存

## 安全設計

- noteのCookie・パスワード・セッショントークンをGitHub Pagesへ保存しない
- マガジンは **`ネロのお気に入り🌙` 完全一致**
- 自動操作失敗時の無条件再送を避ける
- `.github/workflows` は置かない
- Cloudflareは使用しない

## 開発・確認

```bash
npm run check
npm run build:extension
npm run package:extension
```

Android版Firefoxの通常インストールにはMozilla署名済みXPIが必要です。
